# 🤟 KSL 수어 통역 시스템

TensorFlow.js, MediaPipe, Flask를 활용한 실시간 AI 기반 한국 수어 인식 시스템

## ✨ 주요 특징

- **🚀 통합 워크스페이스**: 데이터 수집, 모델 학습, 실시간 통역을 한 곳에서
- **📊 실시간 학습 그래프**: Chart.js를 통한 학습 진행 상황 시각화
- **🎯 목표 기반 수집**: 제스처별 수집 진행률 및 목표 설정 기능
- **🤖 양손 인식**: MediaPipe를 활용한 2개 손 동시 인식
- **📈 진행률 추적**: 각 제스처별 실시간 수집 현황 모니터링
- **⚙️ 학습 프리셋**: 빠른 학습, 균형잡힌 학습, 고정확도 학습 등 사전 설정
- **💾 자동 저장**: 100개마다 자동으로 데이터 저장
- **⌨️ 키보드 단축키**: 생산성 향상을 위한 단축키 지원

## 📋 시스템 요구사항

### 필수
- **OS**: Windows 10/11, macOS, Linux
- **Python**: 3.8 이상
- **브라우저**: 최신 Chrome 또는 Edge
- **웹캠**: 720p 이상 권장

### 권장
- **CPU**: Intel i5 이상 또는 AMD Ryzen 5 이상
- **RAM**: 8GB 이상
- **GPU**: 통합 그래픽 이상

## 🚀 설치 및 실행


```bash

```

### 4. 브라우저에서 접속


## 📖 사용 방법

### 🚀 워크스페이스 (권장)

통합 워크스페이스에서 모든 기능을 한 곳에서 사용할 수 있습니다.

**접속**: http://localhost:5000/workspace

#### 1️⃣ 데이터 수집
1. **제스처 선택**: 오른쪽에서 수집할 제스처 클릭
2. **카메라 시작**: "📹 카메라 시작" 버튼 클릭
3. **녹화 시작**: "🔴 녹화 시작" 버튼 또는 `Space` 키
4. **진행률 확인**: 캠 아래 실시간 프로그레스바 확인
5. **데이터 저장**: "💾 데이터 저장" 버튼 또는 `Ctrl+S`

**편의 기능**:
- ✏️ 목표 수정: 제스처별 목표 개수 변경 (기본 800개)
- 🎨 스켈레톤 ON/OFF: 손 골격 표시 토글
- 💾 자동 저장: 100개마다 자동 저장 (토글 가능)

#### 2️⃣ 모델 학습
1. **프리셋 선택**:
   - ⚡ 빠른 학습 (테스트용)
   - ⚖️ 균형잡힌 학습 (권장)
   - 🎯 고정확도 학습
   - 🏆 전문가 모드
2. **파라미터 조정**: 슬라이더로 에포크, 배치 크기, 학습률 조정
3. **학습 시작**: 최소 2종류 제스처 필요
4. **실시간 그래프**: 📊 정확도와 손실 실시간 모니터링

#### 3️⃣ 실시간 통역
1. **통역 시작**: "🎥 통역 시작" 버튼 클릭
2. **제스처 인식**: 학습된 제스처를 카메라에 보여주기
3. **결과 확인**: 인식된 제스처와 신뢰도 확인
4. **통계 확인**: FPS, 인식 횟수, 평균 신뢰도 모니터링

### 개별 페이지

- **실시간 통역**: http://localhost:5000/
- **모델 학습**: http://localhost:5000/train
- **데이터 수집**: http://localhost:5000/collector

## 🧠 기술 스택

### Frontend
- **TensorFlow.js**: 브라우저 기반 딥러닝
- **MediaPipe Hands**: 손 랜드마크 검출
- **Chart.js**: 실시간 그래프 시각화
- **HTML5 Canvas**: 비디오 오버레이

### Backend
- **Flask**: Python 웹 프레임워크
- **Jinja2**: 템플릿 엔진

## 🎯 학습 팁

### 데이터 수집
1. **목표 설정**: 제스처별 500-1000개 권장
2. **다양성**: 다양한 각도, 거리에서 수집
3. **일관성**: 같은 제스처는 유사하게 수행

### 모델 학습
1. **최소 요구사항**: 2종류 이상 제스처
2. **권장 데이터**: 100개 이상, 5종류 이상
3. **프리셋 활용**:
   - 테스트: 빠른 학습 (20 epochs)
   - 일반: 균형잡힌 학습 (50 epochs)
   - 최적: 고정확도 학습 (100 epochs)

### 인식 정확도 향상
1. **조명**: 밝고 균일한 조명
2. **배경**: 단순하고 손과 대비되는 배경
3. **거리**: 카메라로부터 30-50cm 유지
4. **안정성**: 제스처 0.5초 이상 유지

## 🔧 문제 해결

### 카메라 권한 오류
```
브라우저 주소창 > 자물쇠 아이콘 > 카메라 권한 허용
```

### 학습 오류
- 최소 2종류 이상의 제스처 데이터 필요
- 데이터가 적으면 경고가 표시되지만 학습 가능

### 성능 최적화
- 하드웨어 가속 활성화 (Chrome 설정)
- 다른 프로그램 종료로 리소스 확보
- 스켈레톤 표시 OFF로 성능 향상
